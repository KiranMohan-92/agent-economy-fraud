# Plan 07-01

## Objective

Adversarially test every load-bearing claim, withdraw unsupported conclusions,
repair fail-open implementation paths, and establish a source-backed,
reproducible contract for any future confirmatory work.

## Work packages

1. Independent metric/reproducibility audit.
2. Independent fraud/financial-crime domain audit.
3. Independent agent/protocol/literature audit.
4. First-principles and hard-to-vary causal reconstruction.
5. Label, event identity, fusion, credential, and injection repairs.
6. Manuscript, GPD state, claim ledger, data manifest, and legacy-status repair.
7. Tests, static checks, manuscript checks, GPD regression, and peer review.

## Exit conditions

- unsupported fraud/autonomy/human/banking/robustness claims are withdrawn;
- code cannot silently reproduce legacy semantic errors;
- historical calculations and defects are machine-auditable;
- external blockers remain explicit;
- fresh verification evidence is recorded in `GPD/VERIFICATION-2026-07-09.md`.
