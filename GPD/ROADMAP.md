# Roadmap: integrity repair to confirmatory science

## Historical phases

Phases 1--6 produced useful exploratory code and analysis, but their
verification status is superseded because the central construct, event identity,
label semantics, independence, and reproducibility gates did not pass. The files
remain as an audit trail; completion checkmarks are not scientific validation.

## Phase 7: research-integrity repair

**Goal:** make the repository honest, internally coherent, fail-closed, and
capable of supporting a future confirmatory study.

- [x] 7.1 independent metric/reproducibility, fraud-domain, and literature audits
- [x] 7.2 primary-source verification and hard-to-vary causal reconstruction
- [x] 7.3 label, score, event-key, credential, and injection code repairs
- [x] 7.4 repaired manuscript, evidence vector, claim ledger, and data manifest
- [ ] 7.5 fresh test/static/manuscript/GPD regression and six-pass peer-review gates

**Exit criteria:** all IR requirements complete or explicitly owner-dependent;
no invalid performance or deployment claim remains authoritative; unresolved
external evidence is carried as a blocker rather than guessed away.

## Phase 8: admissible dataset and ground truth

**Status:** blocked pending new evidence.

1. Freeze an event-complete query and release contract.
2. Verify registry/current-wallet/service/execution/payment evidence dimensions.
3. Define separate outcome adjudication for fraud, AML, and market abuse.
4. Complete privacy, governance, and legal review.

**Exit criteria:** CD-01 through CD-05 pass.

## Phase 9: confirmatory evaluation

**Status:** pending Phase 8.

1. Preregister hypotheses, mechanisms, features, benign twins, and falsifiers.
2. Freeze temporal/component splits and incumbent baselines.
3. Run untouched evaluation with calibration, capacity, uncertainty, and
   intervention metrics.
4. Commission independent red-team and external reproduction.

**Exit criteria:** CM-01 through CM-06 pass. A negative result is a valid exit;
post-hoc relabeling of failure is not.

## Phase 10: publication or operational consideration

**Status:** prohibited until Phase 9.

- Publication wording must match the claim ledger and required evidence-vector conjunction.
- Operational consideration additionally requires model-risk, privacy,
  fairness, security, alert-capacity, rollback, and intervention review.
- The current score can never be grandfathered into production based on the
  historical experiment.
